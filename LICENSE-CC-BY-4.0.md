Os dados brutos não são redistribuídos neste repositório. Eles são obtidos diretamente das fontes oficiais pelo script `src/download.py` e seguem os termos de uso de cada fonte:

- População residente: Instituto Brasileiro de Geografia e Estatística (IBGE), Sistema IBGE de Recuperação Automática (SIDRA).
